# AI Quality Engine — Phase 8

Phase 8 is deterministic-first. A verified wedding bible supplies cited facts; SQL supplies private live facts. Unknown questions create a family handoff instead of a guess. A semantic cache avoids repeated work. The provider router reports optional cloud/local providers but leaves them disabled until credentials, quotas and data-use terms are verified.

Quality is gated by 320 synthetic multilingual cases, the 40-pair persona guide, privacy/injection rules and stored evaluation runs. No WhatsApp content or real guest data is used for training or examples.
